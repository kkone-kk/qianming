请将输入的普通中文姓名重新设计成一张完整的「中文个性签名 AI Filter」设计稿。最终画面为 9:16 竖版，上方约占 40%，展示普通印刷姓名；下方约占 60%，展示同一个名字的四种完全不同的艺术手写签名。整体高级、克制、现代、有专业设计提案感，不要像普通字体样张或书法练习纸。

【顶部姓名区】

使用【顶部背景色】作为主色，加入极轻微的纸张或织物质感，并可加入柔和自然的窗影、树影或建筑光影，但不要复杂。顶部中央使用很小、字距宽松的英文“NAME TO SIGNATURE”，中央使用暖象牙白色、规整优雅的中文宋体大字展示【中文姓名】，姓名下方以小字号、宽字距大写英文显示【姓名拼音】。

这里的中文姓名必须保持普通印刷字体，不要手写、连笔或艺术变形，用来明确表现“原始输入”。除此之外不要添加额外标语、解释文案、Logo、编号或装饰图形，保持充分留白，让姓名成为上半部分绝对视觉中心。

【底部签名区】

底部统一使用暖米白色纸张，只保留非常轻微的天然纸纹，不做明显做旧、污渍或强颗粒。使用非常浅、非常细的灰褐色虚线将区域分成 2×2 四格，不需要外边框。每一格只展示一个大尺寸黑色艺术签名，以及下方很小的风格名称：飘逸、锋势、回环、极简。

四个签名全部来源于同一个【中文姓名】，但在结构、方向、节奏、抽象程度、重心和视觉人格上必须有明显差异。不要只是将完整姓名用四种相似连笔方式重新写一遍。允许大胆省笔、合笔、共享笔画、连续连写、拉长、缩写、重构和符号化，不要求每个中文字都完整可辨，重点是从姓名中提炼具有个人识别度的签名结构。

签名使用自然黑色签字笔、钢笔或 gel pen 的真实手写质感，线条带自然笔压变化：起笔较细，主笔略重，转折处有自然压力，快速拖尾逐渐变细，局部允许极轻微断墨。不要生成完全光滑的数字矢量曲线，也不要做成传统毛笔书法。

【飘逸款】

将姓名设计成横向、轻盈、流畅的艺术签名。可以高度压缩中文字形，并让多个字符共享笔画、自然连写，通过一至两条大跨度长线或拖尾把整个姓名连接为完整手势。允许牺牲部分可读性，重点表现流动节奏、速度感和优雅气质。

最终效果应像艺人、设计师或创作者自然签出的成熟个人签名，而不是清楚书写的三个中文字。整体以柔和曲线和连续笔势为主，不要堆叠过多尖角。

【锋势款】

将姓名设计成更加锋利、快速、有力量的签名。大量使用斜线、尖角、高竖笔、快速切线和干脆的收笔，把中文字形高度压缩，只保留几个最有力量的骨架结构。

整体可以明显向右倾斜，形成强烈速度感和现代感。避免大面积柔软圆环，让这款和飘逸款第一眼就形成明显区别，气质偏冷静、果断、有气场。

【回环款】

将姓名设计成以大型回环结构为核心的艺术签名。可以使用开放圆环、自由椭圆、大 S 曲线、丝带式曲线或不规则包围结构，把高度压缩后的姓名笔势自然嵌入回环内部或让其穿过回环，并允许最后一笔突破主体结构形成长收尾。

回环必须具有真人快速书写的自然感，不能像规整几何图形。整体第一眼应更像一个艺术家的个人签名符号，第二眼才感受到它来自原始中文姓名。

【极简款】

这是四种方案中最抽象、最克制的一款。不需要完整写出整个姓名，只从中文字形中提取大约 4–6 个最有识别价值的主笔，例如长横、主竖、折笔、斜线或几个点笔，再重新组合成一个高级、容易记忆的个人视觉标记。

最终效果可以接近 Personal Mark、个人 Logo 或设计师签名。第一眼不要求直接认出完整姓名，但知道原始姓名以后，应能够理解这些笔势与原字结构的关系。保持大量留白，不要添加无关圆圈、箭头、星形或其他装饰符号。

【整体控制】

四款签名必须真正体现不同的人格：飘逸款强调柔长、流动和速度；锋势款强调锐利、力量和斜向结构；回环款强调艺术性、包围关系和图形感；极简款强调省笔、符号化和个人品牌感。

不要让四款只是同一种签名修改尾笔。最终签名既要具有艺术性和明显风格差异，也应保留真实手写感与一定的实际书写可能性。整张画面保持干净、高级、有编辑设计感，不添加 Logo、水印、编号、四角星芒、复杂边框或其他多余装饰元素。
